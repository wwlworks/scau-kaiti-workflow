# 开题方法论 · 单文件完整版（自包含，可直接作为附件交给任何 AI）

> **给 AI 的三行说明**
> 1. 这是一份中文社科（社会工作／公共管理／社会学）**硕士学位论文开题报告**的方法论规格，已对齐华南农业大学正式体例。
> 2. 它只讲**怎么写**，不讲**写什么**——不替你选选题，只帮你把已有材料加工成可被评审接受的研究。
> 3. 凡标 `实测` 的结论有文本统计支撑；凡标 `推断` 的是合成者判断，不是文献共识。

## 一、体例：华农开题报告的五大块

| 块 | 内容 | 篇幅（28 页正文） | 谁打分 |
|---|---|---|---|
| 封面＋登记表 | 学号姓名学院专业导师／题目·选题来源·**论文类型**·开题日期·涉密 | 1.5 页 | 形式 |
| **一、立题依据** | （一）研究背景（二）研究目的及意义（三）国内外研究综述＋**参考文献目录** | **约 13 页（占一半）** | 综述质量 |
| **二、研究内容和目标** | （一）研究内容（二）**论文主要框架**（三）研究目标和成果（四）**拟解决的关键问题** | 4 页 | ★重点 |
| **三、研究方案设计及可行性分析** | （一）研究方法（二）研究框架及思路（三）理论分析 | 3 页 | |
| **四、特色与新颖之处** | 3 条 | 1 页 | 新颖性 |
| **五、研究基础与工作条件** | （一）研究基础（二）**可能出现的问题及解决办法** | 2 页 | 可行性 |
| 工作计划表／经费表／意见评分页 | — | 2 页 | 形式 |

### 七处"暗桩"（不按它写就扣分）

1. **二（三）1"研究目标"实为研究问题清单**——范本写成"第一…第二…第五…"，每条一个待答问题。不要写成"我要写一篇关于 X 的论文"。
2. **二（二）逼你提前写完整三级目录**（1／1.1／1.1.1）——这等于逼你提前做"逐字回收"，是好事。
3. **二（四）关键问题只有 2 条，且是理论层面的**（范本：丰富理论内涵／提炼服务模式），不是经验问题。
4. **五（二）＝讨论章局限的前置**——每条格式必须是「问题 → 为什么是问题 → 我已经有办法」。**确实没办法的不算问题，算局限，移走。**
5. **体例没有独立的概念界定章**——概念只能寄生在 三（三）理论分析。
6. **体例没有"研究边界"的位置**——只能寄生在 二（四）或 三（二）。
7. **页末评分表 6 项是明牌**：导师方向符合度／专业符合度／新颖性／可行性／工作量／总体。照着写＝送分。

## 三、十二道工序（压缩）

| # | 工序 | 一句话动作 | 判据 |
|---|---|---|---|
| 1 | 降落 | 分析单位降三次，每次换证据 | 读者能说出"只能在一线看清" |
| 2 | 造矛盾 | 一对互相加剧的矛盾 | 一个解决不了另一个 |
| 3 | 腾位 | 三处同构"能解释／不能解释" | 三段 β 指向同一处 |
| 4 | 分段 | 综述拆成"漏斗段＋仓库段" | 切换处有过渡句 |
| 5 | 造零件 | 登记 8–18 件 G 零件（G1–G10 十类：概念／维度／阶段／要素／类型学／命题／判据／边界条件／反常事实／工具） | **先分承重件／背景件**：删掉它后文会塌＝承重件，要有落点；塌不了＝背景件，只判篇幅（一句到一段） |
| 6 | 埋接口 | 每小块末句发许可证 | 能答"为后文哪处埋伏笔" |
| 7 | 三层装配 | 解释理论＋操作框架＋过程机制 | 缺一即退化 |
| 8 | 矩阵化 | 做一张表，表头即分析单元 | 留 1–2 格空 |
| 9 | 配观察点 | 每维 3–5 个"看到即发生" | 列不出就降级为视角 |
| 10 | 逐字回收 | 缺口名词＝章标题 | 字面相同，不是意思相同 |
| 11 | 机制五条件 | 转化式＋中间产物＋一手证据＋负案例＋成果不回撤 | 缺负案例＝宣传 |
| 12 | 讨论章 | 回检边界 → 说贡献 → 局限（≤1/4）→ **收尾回贡献** | 最后三句不落在局限上 |

### 三种机制证成路径（选一条，别混）

| | 演绎型 | 归纳型 | 比较型 |
|---|---|---|---|
| 机制来源 | 理论自带 | 编码→主题→机制 | 3–6 个事件成败对照 |
| **证据单位** | 矩阵格 | 编码主题 | **事件** |
| 章节排法 | 按维度 | 按机制 | 按事件 |
| 补救 | **免责声明随柱子立** | 每条配负案例 | 交代事件选择标准＋抽样偏倚 |

### 两个补件（选理论与验收）

**① 理论对话矩阵**（选定前的比较；C6 辩护句是选定后的辩护）
| 我的研究问题 | 候选理论 A | B | C |
|---|---|---|---|
| 子问题 1 | 能解释哪部分？盲区？ | | |

三条原则：不找"唯一正确"的理论／互补常优于单一／**所有候选对同一问题盲区相同 → 你要换的是学科视角**。
补一句：`我选 ____，因为 ____ 能解释而 ____ 不能；我放弃 ____，因为 ____。`

**② 单页论证六段**（装完后的压力测试，六段不写第七段）
`1 我研究 X 因为… → 2 已有研究告诉我们… → 3 但尚未回答… → 4 我用[理论]因为… → 5 因此我的问题是… → 6 为回答这些我用[方法]因为…`
判据：**压不进一页＝有虚节，最常见断在段 4→段 5**（理论没真正推出问题）。

## 四、三份自查清单

### A. 结构自查（12 条，标★致命）

- [ ] ★降落够：降 ≥3 次，每次换证据类型
- [ ] ★矛盾成对且互相加剧
- [ ] 研究边界写下来了（2–3 条 + 理由）
- [ ] ★综述分了漏斗段／仓库段，切换处有过渡
- [ ] 腾位用"解释边界"，三段同构
- [ ] ★零件登记 8–18 件，标了产地
- [ ] 每个小节的末句都是接口
- [ ] ★三层齐（解释／操作／过程）
- [ ] ★每维 3–5 个观察点；列不出的已降级
- [ ] ★缺口名词与章标题字面一致
- [ ] ★每条机制有负案例；成果侧没退回"与…相关"
- [ ] ★讨论章写了，且最后三句落在贡献上

### B. 反防御性自查（8 条）

- [ ] 摘要／引言前两页，四件事都出现了（问题／缺口／思路／结果）
- [ ] 没有在贡献立起来之前谈不足（**批评别人可以早，检讨自己要晚**）
- [ ] 没有把局部现象写成普遍缺陷
- [ ] 没有比证据更宽的负面判断（严重／几乎／全面）
- [ ] 最后三句落在**贡献**上
- [ ] 没把自己不占优的维度设成主战场（质性版：硬谈"普适性"）
- [ ] 每个论点只有一条最强引语
- [ ] 没有"才疏学浅／抛砖引玉／难免疏漏"

**弱点七级处置（命中即停）**：
`删（无关）→ 收（主张比证据宽）→ 换（不是你的战场）→ 转（改写成边界条件）→ 移（放到该在的位置）→ 配（每条局限配对策）→ 说（影响核心结论才正面写）`

### C. 段落自查（8 条）

- [ ] 这段有一句是"作者的判断"吗？能一句话说出来吗
- [ ] 没有在回应一个还没出现的质疑
- [ ] 没有整齐句壳（并非…而是…／不能简单认为…／既…又…）且对照无增量
- [ ] 限定语不超过两个
- [ ] 没有抽象名词平行罗列（跑一次替换检验：换成别的领域还成立吗）
- [ ] 段首承接上文，不重述背景
- [ ] 段尾落在本段认识／下一步，不是"具有重要意义"
- [ ] 语气与材料档位对齐

**信息强度四档**：
`Ⅰ 直接显示（有原话/记录/台账）→ 不加"可能"` ／ `Ⅱ 合理推出（多条材料同向）→"倾向于"` ／ `Ⅲ 尚待验证（线索/单例）→"提示/有待检验"` ／ `Ⅳ 必要边界 → 出现一次，放在结论后`

> **降档比升档危险**：把硬证据说软（"访谈中一位社工可能提到……"）是最常见的自伤。

## 五、行文规格（实测数据支撑）

### 语感五数

| 指标 | 目标 | 依据 |
|---|---|---|
| 句子中位长度 | **48–55 字** | 三篇样本 51–53；低于 45 就滑向"报告体" |
| 句长 90 分位 | **≤100 字** | 三篇 99–101 |
| 段落中位长度 | **150–200 字** | 四篇 144–197 |
| 短段（60–110 字）占比 | **20%–30%** | 四篇 10 分位都在 64–72 |
| **但 : 然而** | **≥10:1** | 三篇 19–22:1 |

**两条频控**：序数（第一/第二…）**≤0.4/千字**（三篇 0.15–0.26，反例 1.93）；**综上／由此可见 ≤全文 6 次**。
**一条禁令**：**"站在…视角／角度" = 0 次**（三篇样本 0 次，只有反例用 6 次）。

### 四种段型

| 段型 | 任务 | 长度 | 骨架 |
|---|---|---|---|
| **判断段**（60%） | 立判断→拆侧面→段末回扣 | 150–220 | `[判断句]。[侧面一，带具体物]。[侧面二，带具体物]。[段末推导判断]。` |
| **定义段** | 划边界＋给具体物 | 80–150 | `X 指 Y，如 Z1、Z2 和 Z3。它不同于 A，……` |
| **证据段** | 让当事人说话再解读 | 120–200 | `[谁] 说："[原话]"。这句话指出……。`（**一段一条引语**） |
| **过渡段** | 只做一件事 | 60–110 | `上一节停在 A。到了 B，什么变了。` |

### 六个局部技术

1. **定义＋如**：`X 指 Y，如 Z1、Z2、Z3。`（一句话完成抽象—具体两次落地）
2. **"与 A 相对的是 B"**：完成对照，**且不触发被禁的"并非…而是…"**。三段式：`[通行做法] 长期被视为[价值]。但其代价是[后果]。与[通行做法]相对的是[本文做法]。`
3. **结论重述定义**：结论章展开发现前，把核心概念的定义再写一遍，让读者在同一坐标系收尾。
4. **自造概念加引号，从一而终**：首次出现加引号并给定义，此后每次出现都加。
5. **"一旦 X 撤离，Y 将难以 Z"**：把条件性判断写成可检验的后果句。
6. **局限三段式**：`限制是什么 → 影响哪条结论 → 我打算怎么办`（每条都要有第三段）。

### 一段三改（看清目标语感）

**报告体**：议事会的参与不足受多重因素影响。第一，时间安排冲突。第二，议题不匹配。第三，缺乏正向反馈。上述三方面共同导致参与不足。

**生硬**：议事会开不起来。没人来。来了也不说话。

**目标**：议事会定在周三下午，来的多是退休的阿姨；年轻人不是不想来，是请不了假。议题也窄，前三次议的都是楼道堆物，第五次之后就不太有人提新的事。更麻烦的是提了未必有回音——上一轮反映的停车位问题，两个月没答复。参与要有回本，回不了本，第二次就不来了。

## 六、十三处禁区（按严重度）

| 1 | **判据与对象同构（循环论证）** | 判据是在接触对象前从文献定的，还是问对象问出来的？ |
| 2 | **章节标题主张了正文否认的命题** | 把每个标题当承诺，翻正文看兑现没有 |
| 3 | **"机制"从未写成一句陈述** | 能用一句话说完机制吗？因变量只有一个吗 |
| 4 | **编码表预制结论** | 编码示例表的主题层，是不是已经是成品答案 |
| 5 | **宣称与样本表裂缝** | 每句"覆盖 X"都对表了吗 |
| 6 | 漏斗倒着画 | 核心概念第一次出场早于它的理论铺垫 |
| 7 | 程序性空降（方法名≠实际程序） | 宣称扎根，展示了开放编码→主轴→选择性的步骤吗 |
| 8 | 讨论章／结论章空缺 | 缺口句在结论处逐条打勾了吗 |
| 9 | 类型学铺了不用 | 我会用它给案例定性吗？答不出就别铺 |
| 10 | 综述没为设计打地基 | N 分框架，综述里有 N−1 个类型吗 |
| 11 | 成熟维度引进却沉默弃用 | 弃用一个成熟维度，写理由了吗 |
| 12 | 两套框架并行、映射未交代 | 框架 A 管章节、框架 B 管编码，写清了吗 |
| 13 | 缺口修辞化（同句重述不增量） | 每处缺口宣告，新增了什么 |

**另有四类机械检查**：文内引用×文献列表双向核对；编号连续性＋"计数词 vs 枚举数"一致；术语一致性；图表真实存在且编号不重复。

## 七、迁移边界（别越界承诺）

**适用**：质性为主、单案例或少量案例、机制／过程取向、有理论对话意图、中文社科。
**不适用**：问卷／实验为主的量化研究；大样本比较；现状描述＋对策建议型（工序 7–11 需大幅简化）；经济学式实证论文。

**三条不可迁移**：
1. 不要照搬"机制三条件"到描述性研究——硬造机制＝过度解释。
2. 不要照搬"三层装配"到理论创新型研究——会被读成"借了别人的框架"。
3. 不要照搬"事件化机制章"到无事件可依的题目。

**一条更根本的**：本规格源自"西方理论本土化改造"的路子。若你的理论资源是国内原创，或研究是"从经验中生成理论"，工序 5 要反过来做——**先有经验，再回填综述**。

## 十、这套东西管不到什么

1. 不管选题价值——结构完美的平庸选题照样能得高分。
2. 不核验外部真实性——只审计结构与写法，不核实文献、访谈、统计。
3. 不替代读文献——零件登记的前提是真读过。
4. 不保证资料可得——机制能写到什么程度，取决于手上有什么材料。
5. 样本量小（三篇论文稿＋一篇期刊论文＋一篇学位论文），`1/3` 的结论只是选项。

**遇到超出范围的要求，直说"这超出这套方法能保证的范围"，不要硬答。**
